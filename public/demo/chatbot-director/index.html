Le problème

Les directeurs ne peuvent pas accéder à leurs données.

01

Avant une réunion de conseil, un directeur doit naviguer dans des tableaux de bord complexes, appliquer les bons filtres, et interpréter les résultats manuellement.

02

Les données sont piégées dans le SaaS. Le directeur a besoin d'un accès simple, immédiat, sans connexion supplémentaire.

03

WhatsApp est le canal privilégié en Amérique Latine. 98% des smartphones l'utilisent. C'est là que les directeurs vivent déjà.

Un directeur stratégique dans votre WhatsApp.

Sécurité

Sécurité par conception, pas par ajout.

✓
Validation SQL déterministe

Regex, pas LLM. OR/UNION interdits. Filtre obligatoire par organisation.

✓
Vérification numérique

Chaque chiffre dans la réponse est vérifié contre les données réelles. Échec → rejet.

✓
Webhook HMAC-SHA256

Signature vérifiée avec comparaison à temps constant. Pas de timing attacks.

✓
Admin 2FA

Allowlist de téléphones + clé secrète. Les deux facteurs requis.

✓
Isolation des données confidentielles

SQLite séparé, jamais versionné. CPL, CAC, ROAS isolés par directeur + organisation.
